Tools that keep files local

File and policy inspection happens in the browser whenever possible. This makes the utilities useful for unpublished assets, internal configuration, and quick checks that do not justify uploading data to a large platform.

Understand the result

CrawlerPolicy separates access rules from downstream AI-use preferences. PrintSpec Lab separates raw pixel dimensions from the DPI required at a target physical size. Both tools expose the reasoning behind the result.
