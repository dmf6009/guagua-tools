What changes at medium difficulty

Medium puzzles start with around 33 givens. Scanning still does much of the work, but you will reach points where no cell can be filled by looking alone. That is the moment to start writing candidates: the small pencil marks that list which digits are still possible in a cell. Learning to use them well is the main skill medium puzzles teach.

Using pencil notes efficiently

Press Notes (or N) and the number pad writes small digits instead of answers. Two habits make notes useful rather than cluttered:

  • Note only cells with two or three candidates at first. A cell with seven possibilities tells you nothing yet.
  • Let the game clean up for you. When you place a correct digit, the same digit is erased from notes in its row, column and box automatically, so your notes stay accurate.

Techniques you will need

Hidden singles in notes. Within one row, column or box, a digit may appear as a candidate in only one cell, even if that cell lists other candidates too. That cell must hold the digit.

Naked pairs. If two cells in the same row, column or box both contain exactly the same two candidates, for example {3, 8}, those two digits must go in those two cells, in some order. Remove 3 and 8 from every other cell in that unit. This often turns another cell into a single.

Pointing pairs. If, inside one box, every possible place for a digit lies in a single row, that digit must be in that row within the box. It can therefore be removed from the rest of that row outside the box. The same works for columns.

These three cover almost every medium puzzle.

A good order of work

  1. Scan for singles as you would in an easy puzzle until nothing more appears.
  2. Write candidates in one box, row or column that is nearly full.
  3. Look in those notes for hidden singles and naked pairs.
  4. Each new digit you place may open more scanning; return to step 1.

Typical times

Regular players finish medium puzzles in about 8 to 15 minutes. Your first few may take half an hour, mostly spent learning to read notes.

When to move up

When you can solve medium puzzles without hints and the naked pair has become something you notice without searching, try hard Sudoku. If medium is too much today, easy Sudoku is a good place to build speed.

Frequently asked questions

How many givens does a medium Sudoku have?

About 33 of the 81 cells. Difficulty is set by removing givens while keeping exactly one solution.

Does every puzzle have only one solution?

Yes. Each puzzle is generated in your browser and checked by a solver so that exactly one solution exists. You never need to guess.

Is my progress saved?

The current puzzle, your notes and the timer are saved in this browser's local storage, so you can close the page and continue later. Nothing is sent to a server.
