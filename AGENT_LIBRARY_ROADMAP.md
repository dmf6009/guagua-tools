# Expert Agent Blueprint Library Roadmap

The source inventory contains 419 Workbuddy agent packages. Guagua Tools will not mirror them wholesale. Each published page must serve an international search intent, stand alone without proprietary services, and add an original workflow, example, guardrails, and output contract.

## Selection rubric

- International usefulness and recognizable job-to-be-done: 30%
- Search intent and long-tail page potential: 25%
- Ability to demonstrate a concrete output: 20%
- Safe, evergreen subject matter: 15%
- Fit with the existing MCP and agent-tool audience: 10%

Agents tied to China-only platforms, private corporate systems, personalities, live financial/legal/medical advice, or unclear third-party assets are excluded from the first releases.

## Phase 3 — creator and small-business workflows

Brand Guardian, Content Distribution Strategist, Customer Support Expert, Study Planner, Market Researcher, Proposal Strategist, Supply Chain Strategist, and Tool Evaluation Expert.

## Publishing requirements

Each page includes original English copy, a task-oriented title, use cases, inputs, workflow, output contract, guardrails, worked example, starter prompt, FAQ, and related links. AdSense code is present globally, while interactive copy controls and prompt blocks remain ad-free zones. Pages are added to the XML sitemap only after editorial and link checks pass.
