This is no longer a catalogue of every possible agent role. It is a maintained set of engineering workflows that match the tools and field notes on this site. Each package exposes its instructions in plain text, states where human judgment is required, and can be reviewed before installation.

What “maintained” means

Instructions you can inspect before you trust.

Readable source

Every ZIP includes the same plain SKILL.md linked on the page. There are no bundled credentials, executable hooks, or hidden remote services.

Explicit boundaries

Each workflow says what evidence it needs, what it should return, and which decisions still belong to a human owner.

Corrections are public

The site source and issue history live on GitHub. The testing and editorial method explains how examples and updates are reviewed.
