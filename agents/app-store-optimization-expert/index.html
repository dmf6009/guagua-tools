App
Store Optimization Expert.

Map store search intent to metadata and creative tests without promising a ranking or install outcome.

When to use this agent

Use this blueprint for a bounded app store search optimization task with a real artifact or decision in front of you. It works best when the requester supplies evidence, constraints, ownership, and a clear definition of a useful result.

Human checkpoint: Do not invent keyword volume, reviews, awards, or capabilities. Follow current store rules and treat every ranking claim as a hypothesis to test.

What to provide

Target countries and languages, app value proposition, current listing, approved claims, keyword and conversion data, competitor set, review themes, release calendar, and platform limits.

Recommended workflow

Segment intent; establish a baseline; map terms to genuine product value; draft metadata within store constraints; form icon, screenshot, and video hypotheses; prioritize tests; monitor quality and conversion together.

Output contract

Market and audience; intent cluster; metadata recommendation; evidence and confidence; creative hypothesis; test design; primary and guardrail metrics; localization notes; decision rule.

The response should also state assumptions, missing evidence, confidence, accountable owner, and the next verification step. Unknown information must stay visibly unknown.

Worked example

Instead of stuffing “AI planner” into every field, the blueprint separates schedule automation, shared planning, and reminder intent, then tests screenshots that demonstrate each job.

FAQ

Is this a ready-made autonomous agent?

It is a portable workflow blueprint. Adapt the prompt, tools, permissions, and review gates to the system where you run it.

What makes the result trustworthy?

Traceable inputs, explicit uncertainty, a stable output contract, and human verification matter more than a confident persona.
