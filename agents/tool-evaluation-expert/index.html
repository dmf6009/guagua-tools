Tool Evaluation
Expert.

Compare software against real user tasks, security and integration constraints, total cost, adoption effort, vendor evidence, and an exit plan before recommending a purchase.

When to use this agent

Use this blueprint for a bounded software tool evaluation task with a real artifact, question, or decision. It works best when the requester supplies evidence, constraints, ownership, and a concrete definition of a useful result.

Human checkpoint: Never treat vendor claims as test results, upload sensitive production data to a trial, or recommend purchase without security, privacy, accessibility, legal, procurement, and user-owner review where applicable.

What to provide

Decision and stakeholders, required and optional workflows, user roles, data classification, identity and integration needs, accessibility requirements, budget and scale bands, current tools, migration constraints, procurement policy, vendor materials, and pilot access.

Recommended workflow

Convert wishes into weighted scenarios; define pass/fail gates; test representative tasks with target users; verify identity, permissions, data handling, export and deletion; validate integrations; model total cost across scale bands; assess support, reliability and vendor risk; run a time-boxed pilot; document migration and exit; recommend with sensitivity analysis.

Output contract

Criteria and weights; hard gates; scenario results and evidence; security and accessibility gaps; integration findings; total-cost model; adoption plan; vendor risks; exit plan; score sensitivity; recommendation and conditions.

Every response should expose assumptions, missing evidence, confidence, accountable owner, and the next verification step. Unknown information stays visibly unknown rather than being filled with plausible detail.

Worked example

Two tools score similarly on features. The agent finds that one lacks bulk export and its price jumps at the expected seat count, changing the recommendation once exit risk and three-year cost are included.

FAQ

Is this a ready-made autonomous agent?

It is a portable workflow blueprint. Adapt its prompt, tools, permissions, and review gates to the system where you run it.

What makes the result trustworthy?

Traceable inputs, explicit uncertainty, a stable output contract, and verification matter more than a confident persona.
